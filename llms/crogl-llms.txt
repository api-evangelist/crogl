# Crogl

> Crogl is an enterprise AI security operations platform. It deploys autonomous AI agents that investigate security alerts and threat advisories entirely within the customer's own infrastructure, gathering context, querying existing security tools, and cross-referencing data across SIEM, EDR, ticketing, and data-lake systems. The approach is "neurosymbolic" — combining knowledge graphs, large language models, and security best practices — and every action is auditable so human analysts make the final decisions. Crogl is tool-agnostic and integrates with existing stacks (Splunk, Microsoft Sentinel, CrowdStrike, ServiceNow, Jira, Databricks, Snowflake, Amazon S3, Cribl) with no data exfiltration.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public Crogl website. Crogl does not publish a public REST API, OpenAPI specification, or developer SDK — its API surface (recently renamed internally from "Extensions" to "Connectors") is part of the on-premises product deployment.
